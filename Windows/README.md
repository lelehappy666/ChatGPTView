# Windows 11 版本使用说明

## 打包环境

1. 使用 Windows 11 x64。
2. 保持项目目录结构完整，不要只复制 `Windows` 文件夹。
3. 电脑可以访问微软的 .NET 下载地址。

## 一键打包

在项目根目录双击 `build-win11.bat`。如果电脑没有 .NET 8 SDK，脚本会先询问是否下载；输入 `Y` 后会显示微软官方安装脚本的下载与安装进度，并把 SDK 安装到项目内的 `.tools\dotnet`，不需要管理员权限。安装验证通过后会自动继续 Release、自包含、单文件打包，并生成：

```text
dist-win11\ChatGPT.exe
```

生成的 EXE 不要求目标电脑另外安装 .NET 运行时。

打包前会自动检查 100%、125%、150%、175% 和 200% DPI 下的窗口尺寸、标题横排、标签命中、活动格命中与统计卡片安全边距。检查失败时不会生成 EXE。

## 数据目录

应用默认读取：

```text
%USERPROFILE%\.codex\sessions
```

如果该目录还不存在，先在 Windows 版 Codex 中运行至少一个会话。

## 功能

- 屏幕顶部中央显示 `ChatGPT · Week xx% · 项目状态`。
- 鼠标停留在顶部胶囊约 80 毫秒后自动展开，移出整个窗口约 180 毫秒后自动收起。
- 顶部窗口每次真正展开时会额外请求一次额度刷新。
- 界面使用 Windows 11 深色材质和统一全自绘布局，不依赖第三方 UI 库。
- 中文使用微软雅黑 UI，英文和数字使用 Segoe UI Variable，并根据当前屏幕 DPI 等比例缩放。
- 每日活动格子悬停立即显示当天 Token 和会话数。
- 右下角系统托盘支持刷新、开机启动和退出。
- 完成通知使用真实 `session_id + turn_id` 精确区分会话轮次；缺少轮次 ID 时不会猜测或通知。
- 新完成轮次会等待 3 秒、主动刷新并再稳定 1 秒，只有状态、轮次与完成时间仍完全一致才发送通知和播放系统通知音。
- 同一会话开始新轮次、重新运行或报错时，会立即取消上一轮尚未发送的完成通知。

## 数据刷新频率

- 应用启动时立即刷新一次。
- `%USERPROFILE%\.codex\sessions` 中会话文件发生变化后，约 350 毫秒刷新。
- 顶部窗口从收起状态展开时，约 350 毫秒刷新。
- 托盘“立即刷新数据”触发后，约 350 毫秒刷新。
- 扫描过程中出现的新刷新请求会排队补扫，不会因上一轮尚未结束而丢失。
- 应用不使用固定轮询，避免无数据变化时持续扫描磁盘。

## 通知看不到时

打开 Windows 11 的“设置 → 系统 → 通知”，确认允许 `ChatGPT` 发送通知，同时关闭“请勿打扰”。

## 开机启动

右键系统托盘中的 ChatGPT 图标，勾选“开机自动启动”。取消勾选即可关闭。

## 真机视觉检查

建议分别在 Windows“设置 → 系统 → 屏幕 → 缩放”中选择 100%、125% 和 150% 检查：

- 收起胶囊完整显示 ChatGPT 图标、`ChatGPT`、`Week xx%` 和项目状态。
- 三个标签页文字清晰且不重叠。
- 周额度、每日活动和统计总览没有文字裁切。
- “当前 / 最长连续”卡片底部保留安全距离。
