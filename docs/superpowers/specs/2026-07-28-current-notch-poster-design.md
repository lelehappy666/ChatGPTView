# Codex Monitor 当前刘海界面海报设计说明

## 目标

为项目 README 生成一张 16:9 横版产品海报，严格展示当前 macOS 软件中的刘海数据面板。海报重点是完整、清晰地呈现五个分页，不重新设计面板，不增加软件中不存在的功能或数据。

## 输出规格

- 画布比例：16:9。
- 交付尺寸：3840 × 2160 像素，并保留可缩小用于 README 的高清 PNG。
- 文件位置：`docs/designs/codex-monitor-current-notch-poster-v1.png`。
- 语言：软件界面和海报文字均使用当前项目中的中文文案。

## 构图

采用已确认的“五页产品矩阵”方案：

1. 顶部为克制的品牌区，只展示 Codex Monitor 应用图标、产品名称和当前菜单栏状态胶囊。
2. 第一排居中排列两个等比例刘海面板：
   - 本周额度
   - 每日活动
3. 第二排居中排列三个等比例刘海面板：
   - 项目分析
   - 统计总览
   - GitHub 活跃
4. 五个面板保持相同视觉尺寸，统一使用当前软件的 420:320 宽高比例。
5. 画布背景使用接近黑色的深色渐变，只增加轻微紫色环境光和非常克制的面板阴影。

## 严格还原规则

- 面板内部通过当前源码中的实际 SwiftUI 视图和同一份当前数据快照逐页渲染为 PNG。
- 不改变标题、字号、间距、圆角、分页指示点、热力格、图表、进度条、项目列表、GitHub 图标和数字格式。
- 不让图像生成模型重新绘制面板内部文字、数字或图表。
- 五页使用同一次数据快照，避免不同页面的今日数据、累计数据和项目数据互相矛盾。
- 不使用旧设计稿替代当前实现，不加入早期设计中已经取消的布局。
- 不展示桌面、聊天窗口、用户名之外的个人内容或其他应用信息。

## 视觉层级

- 第一层：五个真实刘海面板，是海报主体。
- 第二层：Codex Monitor 名称和菜单栏状态，说明产品身份。
- 第三层：深色背景、紫色柔光和轻微阴影，只负责衬托，不抢占界面注意力。

## 制作方式

1. 从当前 `main` 分支构建产物中获取五个分页的真实视觉基准。
2. 使用同一份当前数据分别渲染五个页面。
3. 仅使用图像生成能力制作无文字的深色紫光背景。
4. 通过确定性的图像合成放置真实面板、应用图标、产品名和菜单栏状态。
5. 输出 4K PNG，并生成 README 使用尺寸。

这种方式可以保留海报氛围，同时避免生成模型导致中文乱码、数字错误、格子变形或布局偏移。

## 验收标准

- 画面中完整出现五个当前刘海分页，顺序正确。
- 五个面板宽高比一致，内部没有拉伸或裁切。
- 面板内部视觉与当前软件一致，不出现虚构文字和数据。
- 16:9 画布在 README 首屏中仍可读，标题和关键数字清晰。
- 背景没有其他应用、桌面文件或隐私信息。
- 最终文件可直接在 GitHub README 中引用。
