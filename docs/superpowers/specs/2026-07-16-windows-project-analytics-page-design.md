# Windows 项目分析页面设计规格

## 目标

将 macOS 已确认的「项目分析」能力同步到 Windows 11 原生监控器。Windows 展开面板由三页扩展为四页，顺序固定为：

1. 周额度；
2. 每日活动；
3. 项目分析；
4. 统计总览。

Windows 当前不包含 GitHub 页面，本次不新增 GitHub 授权或仓库数据。

## 数据口径

- 项目名称继续使用会话 `cwd` 最后一级目录；
- 同一 `session_id` 只保留 `updated_at` 最新的摘要；
- 支持最近 7 天、最近 30 天和全部历史；
- 会话 Token 全部归入会话开始日期；
- 展示活跃项目、项目 Token、项目会话；
- 项目按 Token 降序、会话数降序、名称升序稳定排名；
- 不超过六个项目时逐项展示；
- 超过六个项目时展示前五名，第六行汇总为「其他项目」；
- 悬停项目行显示会话数、活跃天数和单次平均 Token。

## 后台处理

Windows 已有 JSONL 文件指纹缓存，未变化文件不会重复解析。项目统计在后台刷新任务中基于已缓存的会话摘要生成三个时间范围快照，界面切换范围时不访问磁盘、不重新扫描会话。

## 界面

- 顶部导航改为四个等宽标签；
- 项目分析页顶部右侧显示 `7 天 / 30 天 / 全部` 三个按钮；
- 按钮视觉矩形与鼠标命中矩形完全一致；
- 中部显示三张紧凑摘要卡；
- 下方最多显示六条排名，每行包含名称、相对第一名的紫色条、Token 和真实占比；
- 鼠标悬停排名行时高亮，并显示原生 ToolTip 明细；
- 空数据时显示「这个时间范围还没有项目数据」。

## 性能

- JSONL 扫描和项目聚合都在后台任务中完成；
- 绘制阶段只读取不可变快照；
- 鼠标移动只做矩形命中和局部重绘；
- 不增加模糊、持续动画或额外定时器；
- 不引入第三方 NuGet 包。

## 打包

使用 .NET 8 发布 `win-x64`、自包含、单文件可执行程序，输出到：

```text
dist-win11/ChatGPT.exe
```

按用户要求，本次不运行布局检查或自动化测试。
