# 项目状态过期与应用图标设计

## 目标

- 顶部菜单栏只展示最近 60 秒内发生过操作的项目。
- 任何状态超过 60 秒没有操作后都从顶部消失，包括进行中、完成和报错。
- 没有可展示项目时，顶部不显示“暂无项目”或任何项目状态占位。
- 为 Codex Monitor 增加原创 macOS 应用图标，并用于 Finder 与系统通知。

## 项目状态过期

### 统一规则

- 使用项目最新事件的 `updatedAt` 作为最后操作时间。
- `当前时间 - updatedAt < 60 秒` 时项目可见。
- 达到或超过 60 秒时项目不可见，不区分项目状态。
- 新事件到达后更新 `updatedAt`，重新开始计算 60 秒。
- 项目完成通知仍在状态从进行中变为完成时发送，不受顶部过期展示影响。

### 双层过滤

- 数据聚合层使用统一可见性策略，避免新快照包含已过期项目。
- 顶部菜单栏现有 4 秒计时器同时重新过滤当前快照，确保没有文件变化时也能自动隐藏。
- 因计时器粒度为 4 秒，项目会在最后操作后的 60 至 64 秒内从顶部消失。
- 鼠标悬停只暂停项目轮播，不暂停过期清理。

## 完成通知准确性

- 应用启动后的首个真实数据快照只用于建立基线，不发送历史项目完成通知。
- 后续以项目的 `updatedAt` 作为完成事件标识，同一完成时间只提醒一次。
- 新项目即使在两次刷新之间快速完成、没有被采样到“进行中”，只要出现新的完成时间也应提醒。
- 项目再次运行并在更晚时间完成时，应再次提醒；失败和进行中状态不触发完成提醒。

## 应用图标

### 视觉语言

- 采用全幅方形图稿，由 macOS 在 Finder、通知和应用选择器中应用统一圆角遮罩。
- 深色渐变底与现有黑色刘海窗口保持一致。
- 顶部使用黑色刘海元素，强调本应用的核心交互位置。
- 中央使用紫色环形额度指示符，表达额度监控。
- 右侧使用橙色运行点，与顶部“进行中”状态保持一致。
- 内部使用简化活动柱形，表达 Token 与每日活动统计。
- 不使用 OpenAI 或 ChatGPT 官方商标图形，保持应用图标原创且可区分。

### 资源与打包

- 使用 Swift/Core Graphics 脚本生成 1024 像素主图和完整 macOS 图标尺寸，并直接写入标准 ICNS PNG 分块，避免依赖不同系统版本的转换工具行为。
- 输出 `Resources/AppIcon.icns`，同时保留 `Resources/AppIconPreview.png` 供预览。
- `Info.plist` 增加 `CFBundleIconFile = AppIcon`。
- 打包脚本将 `AppIcon.icns` 复制到应用包 `Contents/Resources`。
- 图标脚本可重复运行，确保后续修改能够稳定再生成。

## 测试与验证

- 验证进行中、完成和报错项目在 60 秒时全部过期。
- 验证 60 秒内项目仍可见。
- 验证菜单栏使用同一可见性策略。
- 验证首次快照不误报、快速完成不漏报、相同完成时间不重复提醒。
- 验证 `Info.plist` 声明图标，打包应用包含 `AppIcon.icns`。
- 渲染并目视检查 1024 像素图标。
- 运行完整测试、重新打包并验证签名。
