# 菜单实时数字滚动修复设计

## 问题

菜单面板虽然已经使用 `MenuRollingNumberText`，但实际看不到数字从零滚动到实时数据。受影响范围包括每日活动、统计总览、GitHub 活跃以及其他动态指标。

## 根因

现有组件接收的是已经格式化完成的字符串，例如 `2.7 亿`、`44` 或 `5 天`。组件只执行两次状态更新：

1. 将字符串设置为零值文字。
2. 将字符串替换为最终文字，并应用 `.contentTransition(.numericText())`。

该过渡只处理旧文字和新文字之间的字形切换，不会计算数值中间状态。零值更新后只执行一次 `Task.yield()`，SwiftUI 仍可能把零值和最终值合并在同一次画面提交中。因此延长动画时长只能延长文字过渡参数，不能产生用户需要的逐值计数。

## 目标

- 每次打开面板，动态指标从真实数值零开始逐帧增长到当前数据。
- 动画过程中展示按当前插值数值格式化的实时中间值。
- 面板打开期间刷新数据时，从当前显示值平滑滚动到新值。
- 保留原有布局、格式、悬停打开、自动收回和辅助功能行为。

## 覆盖范围

### 本周额度

- 剩余额度。
- 本周已用比例。
- 距离重置的天数和小时。

### 每日活动

- 今日 Token。
- 今日会话数。
- 平均每日 Token。
- 连续使用天数。

### 项目分析

- 最近七天 Token 总量。
- 项目排名中的 Token 数值。
- Token 柱状图继续使用现有高度动画。

### 统计总览

- 累计 Token 数。
- 峰值 Token 数。
- 最长任务时长。
- 当前连续天数。
- 最长连续天数。

### GitHub 活跃

- 总贡献数。

## 排除范围

- `最近 8 周`、`7 天`、`30 天`等静态文字。
- 月份、日期、星期。
- 仓库相对更新时间。
- 底部自动刷新说明。
- 热力图和项目行的鼠标悬停提示。
- 刘海分页界面与 Windows 端。

## 方案

### 数值格式类型

新增菜单数值格式枚举，统一把插值中的 `Double` 转为最终展示文字：

- 普通整数。
- 带千位分隔的整数。
- 百分比。
- Token 的万/亿紧凑格式。
- 天数。
- 普通任务时长。
- 重置倒计时的天数与小时。

格式化时对插值数值进行合理取整，确保画面展示的是可读的真实中间值。

### 可插值数字视图

新增内部可动画数字视图：

- `animatableData` 使用 `Double`。
- SwiftUI 在零值和目标值之间逐帧插值。
- 每一帧使用数值格式类型重新生成文字。
- 外部字体、颜色、缩放、对齐和固定布局继续通过环境继承。
- 无障碍标签始终读取最终实时数据，而不是动画中间值。

### 数字滚动容器

重构 `MenuRollingNumberText`：

- 输入从 `targetText`、`zeroText` 改为可选的原始数值和格式类型。
- 数值缺失时显示 `—`，不执行动画。
- 每次面板展示周期变化时：
  1. 无动画设置为零。
  2. 等待约 60 毫秒，确保零值至少提交一帧。
  3. 用 1.2 秒缓出动画更新目标数值。
- 刷新导致原始数值变化时，从当前呈现状态过渡到新目标。
- 动画任务在视图消失或新任务开始时取消。

### 展示周期时机

展示周期从 `showPopover()` 调用前移动到 `popoverDidShow(_:)`：

- 先确保面板已经由 AppKit 显示。
- 再通知所有数字回到零值并开始动画。
- 避免动画在隐藏状态下提前播放。

## 数据接入

每个面板区块改为传递原始数据：

- 百分比传递 `Double`。
- Token、会话、贡献和天数传递整数转换后的 `Double`。
- 时长传递秒数。
- 重置倒计时传递剩余秒数。

格式化只发生在统一数字视图内部，不再由调用方提前生成字符串。

## 动画节奏

- 零值可见等待：约 60 毫秒。
- 数字插值：1.2 秒，缓出曲线。
- 项目柱状图：1.0 秒，缓出曲线。
- “减少动态效果”开启时不等待、不插值，直接展示最终数据。

## 错误和边界处理

- 原始值为空时显示 `—`。
- 负数或无效值按各指标现有规则归零或格式化。
- 动画过程中目标数据再次更新时取消旧任务，以最新实时值为目标。
- 面板关闭时取消数字动画任务。
- 快速反复打开时，只有最新展示周期可以更新数值。
- 统计总览的大数值继续使用万/亿紧凑格式，不扩大布局宽度。

## 验证策略

### 单元验证

- 零值到目标值之间能生成不同的中间展示文字。
- Token 插值保持万/亿格式。
- 百分比、天数、时长和重置倒计时格式正确。
- 缺失数据保持 `—`。
- 每次展示周期从零值开始。
- 减少动态效果时直接使用目标值。

### 集成验证

- 每日活动四项全部传递原始数值。
- 统计总览五项全部传递原始数值。
- GitHub 总贡献数传递原始数值。
- 本周额度和项目分析继续覆盖。
- 面板展示后才开始新的数字周期。
- 现有布局和完整测试保持通过。

## 完成标准

- 打开面板时，可以明确看到动态指标从零逐值增长。
- 最终显示值与实时数据一致。
- 每日活动四项、统计总览五项和 GitHub 贡献均有可见动画。
- 刷新后数字从当前值平滑变化到新值。
- 静态数字不播放动画。
- 动画时不引起布局跳动或菜单交互卡顿。
