# 即时热力格提示与高对比运行状态设计

## 目标

- 鼠标进入每日活动格子后立即展示该日数据，不依赖 macOS 延迟出现的系统帮助提示。
- 顶部菜单栏中的“进行中”状态在深色、浅色及透明菜单栏材质上都能快速辨认。

## 交互设计

### 每日活动格子

- 使用 SwiftUI 自定义悬停状态替代 `.help`。
- 指针进入任意格子时立即显示浮层；离开该格子时隐藏。
- 浮层显示日期、Token 数和会话数；无活动日期显示“无活动”。
- 浮层位于热力图上方并使用固定布局空间，避免被刘海窗口边界裁切或遮挡其他统计数据。

### 菜单栏进行中状态

- 运行色改为高饱和系统橙色 `#FF9F0A`。
- “进行中”使用实心橙色胶囊和深色粗体文字，不再依赖半透明彩色背景。
- 状态圆点同步使用橙色和适度光晕；项目名称保持系统主文字色。
- 完成和报错状态保持现有语义色。

## 实现边界

- 只调整状态视觉和热力格悬停展示，不修改扫描、额度或项目状态数据来源。
- 保持现有 420 × 260 刘海窗口尺寸和最近 56 天数据布局。

## 验证

- 单元测试验证运行色为 `#FF9F0A`。
- 单元测试验证悬停展示策略为即时、自定义提示。
- 运行完整测试并重新打包，验证应用签名。
