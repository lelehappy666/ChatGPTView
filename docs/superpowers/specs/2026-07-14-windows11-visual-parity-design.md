# Windows 11 视觉一致性优化设计规格

## 目标

将 Windows 11 版 ChatGPT 监控器的顶部胶囊与展开窗口重新实现为全自绘界面，使其在常见 Windows DPI 比例下保持与已确认设计稿一致的尺寸、层级、字体、颜色和质感，同时保留现有数据读取、托盘、开机启动与完成通知功能。

## 问题根因

当前界面使用 WinForms 的 `Label`、`Button` 和 `Panel` 组合固定像素布局。Windows 会根据系统字体与 DPI 对这些控件分别测量和缩放，中文字体回退后产生额外字宽和行高，最终导致图标裁切、标题省略、标签错位、字号失真以及展开页面内容拥挤。原生控件各自绘制背景和文字，也无法稳定呈现设计稿中的统一圆角、半透明层次和细描边。

## 技术方案

保留 .NET 8 Windows Forms、现有单文件 EXE 打包方式及数据层，将 `TopIslandForm` 的可见内容改为统一的 GDI+/DWM 全自绘画布。

- 使用一套 100% DPI 下的逻辑坐标描述收起与展开布局。
- 根据窗口当前 `DeviceDpi` 统一计算缩放比例，所有坐标、圆角、描边和字号使用同一比例换算。
- 通过 `OnPaint` 一次性绘制背景、文字、图标、标签、进度条、热力格和统计卡片。
- 使用 DWM 深色窗口与 Windows 11 系统背景材质；系统不支持时回退到不透明深色背景。
- 删除会参与独立字体测量和自动缩放的可见 `Label`、`Button`、`Panel` 布局。
- 点击与悬停使用逻辑矩形命中测试，不依赖可见子控件。

## 收起状态

- 逻辑尺寸固定为 286×48，窗口位于当前屏幕工作区顶部中央，顶部间距为 8。
- 背景为近黑色半透明胶囊，圆角为 24，外侧使用一像素低对比描边。
- 从左到右依次显示 ChatGPT 图标、`ChatGPT`、`Week xx%` 标签和项目状态。
- `ChatGPT`、周额度和项目状态始终横向排列，不换行。
- 项目名称使用剩余可用宽度；确实超长时才在末尾显示省略号，不能影响周额度显示。
- 运行中使用高对比橙色，完成使用绿色，报错使用红色，无任务使用灰色。

## 展开状态

- 逻辑尺寸固定为 430×300，顶部标题区域与收起状态保持相同视觉位置。
- 展开动画使用约 180 毫秒的三次缓出曲线，并始终保持顶部居中。
- 内容区提供“周额度”“每日活动”“统计总览”三个标签页。
- 当前标签使用深灰抬升背景和白色文字，其他标签使用透明背景和次级文字色。

### 周额度

- 左侧显示“剩余周额度”和大号剩余百分比。
- 中间使用细分隔线。
- 右侧显示“本周已用”、横向进度条、距离重置和同步状态。
- 无真实数据时统一显示 `--`，不生成假百分比。

### 每日活动

- 左侧显示最近 60 天、12 列×5 行活动格子。
- 格子使用五档深紫色强度，圆角、间距和边缘保持统一。
- 鼠标进入格子后立即显示日期、Token 数与会话数。
- 右侧显示今天 Token、会话数、平均每天 Token 和连续使用天数，所有数值完整可见。

### 统计总览

- 使用 2×2 卡片布局。
- 分别显示累计 Token、峰值 Token、最长任务时长、当前/最长连续天数。
- 卡片标题与数值保留安全边距，禁止底部裁切和自动省略。

## 字体与绘制质量

- 英文、数字优先使用 `Segoe UI Variable`。
- 中文优先使用 `Microsoft YaHei UI`，不可用时回退到系统界面字体。
- 文本使用 ClearType 网格拟合与明确的单行裁切规则。
- 不使用浏览器字体或依赖机器上未预装的字体文件。
- 图标使用矢量路径或高分辨率资源按比例绘制，不能使用单字符模拟 ChatGPT 图标。

## 视觉令牌

- 窗口底色：`RGB(8, 10, 15)`，系统材质可用时叠加 92% 深色遮罩。
- 卡片底色：`RGB(18, 21, 29)`；选中标签底色：`RGB(25, 29, 39)`。
- 描边：`RGB(53, 58, 72)`；主文字：`RGB(245, 247, 252)`；次级文字：`RGB(163, 171, 190)`。
- 紫色强调：`RGB(165, 138, 245)`；绿色：`RGB(79, 220, 146)`；橙色：`RGB(255, 166, 72)`；红色：`RGB(255, 102, 123)`。
- 页面左右安全边距为 18，卡片间距为 10，正文基准字号为 13 像素，标题基准字号为 14 像素，大号额度数值为 40 像素。
- 所有数值均为 100% DPI 下的逻辑像素，其他 DPI 按统一比例换算。

## DPI 与多屏

- 支持 100%、125%、150%、175% 和 200% DPI。
- 窗口跨屏时根据目标屏幕 DPI 重新计算物理尺寸和区域。
- DPI 改变后重建窗口圆角区域、阴影和命中矩形。
- 设计逻辑尺寸不因字体自动缩放而改变。

## 交互与兼容性

- 单击收起胶囊展开，单击标题区域收起。
- 标签页切换、活动格悬停和托盘“打开监控”继续可用。
- 窗口保持置顶、不抢夺输入焦点、不显示在任务栏。
- 现有 JSONL 数据解析、刷新、通知和开机启动行为不在本次视觉改造中更改。
- 不新增第三方 NuGet 依赖。

## 验证方式

- 将布局尺寸、页面区域和命中矩形抽取为纯计算模型，先编写失败的布局契约检查，再实现绘制代码。
- 在构建脚本中运行无第三方依赖的布局契约检查，覆盖收起/展开尺寸与三个页面的安全边距。
- Windows 真机分别在 100%、125%、150% DPI 下检查截图。
- 验证所有文字无裁切、周额度横向排列、图标完整、统计卡片完整、活动格悬停即时出现。
- 验证最终仍由 `build-win11.bat` 生成 `dist-win11\ChatGPT.exe`。

## 验收标准

1. 收起与展开界面的视觉结构、间距、圆角、颜色和字号与确认设计稿一致。
2. 用户截图中出现的图标裁切、文字像素感、`ChatGPT`/`Week`/项目名省略及页面错位全部消失。
3. 常见 DPI 比例下不发生控件重叠、文字裁切或窗口尺寸漂移。
4. 周额度、每日活动和统计总览三页数据均完整显示。
5. 原有托盘、刷新、开机启动、数据读取和完成通知功能保持可用。
