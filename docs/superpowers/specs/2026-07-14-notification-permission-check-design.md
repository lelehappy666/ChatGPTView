# 通知权限启动检测设计

## 目标

- Codex Monitor 每次启动时检查通知权限和通知能力。
- 通知权限与横幅、声音均可用时不打扰用户。
- 首次尚未决定权限时，显示 macOS 系统授权请求。
- 权限被拒绝或横幅、声音被关闭时，显示中文提示并提供通知设置入口。

## 权限状态与行为

### 尚未决定

- 调用系统通知授权请求，同时申请提醒和声音。
- 用户允许后静默继续。
- 用户拒绝后显示应用内提示，引导进入系统通知设置。

### 已授权且功能完整

- 授权状态为已授权或临时授权。
- 横幅提醒和声音均未被禁用。
- 不显示任何提示，不打开系统设置。

### 权限或功能不完整

- 授权状态为拒绝，或横幅提醒被关闭，或声音被关闭。
- 显示应用内提示：“Codex Monitor 需要通知权限，才能在项目完成时提醒你。请在系统设置中开启通知横幅和声音。”
- 提供“打开通知设置”和“稍后”两个按钮。
- 只有用户点击“打开通知设置”时才跳转，避免应用启动时强制切走当前窗口。

## 系统设置跳转

- 优先打开 macOS 通知设置中的 Codex Monitor 页面。
- 若当前系统不支持应用级深链接，则退回通知设置总页。
- 跳转失败不会影响监控、额度或项目状态功能。

## 组件边界

- `NotificationPermissionPolicy` 将授权状态、横幅状态和声音状态转换为启动动作。
- `ProjectCompletionNotifier` 查询系统设置、申请授权并执行对应动作。
- `AppDelegate` 每次启动调用一次权限检查。
- 完成通知的状态转换检测与通知内容保持不变。

## 测试

- 验证尚未决定时返回“申请授权”。
- 验证已授权且横幅、声音开启时返回“无需操作”。
- 验证拒绝、横幅关闭或声音关闭时返回“提示设置”。
- 验证临时授权且功能完整时不提示。
- 运行完整测试并重新打包验证签名。
