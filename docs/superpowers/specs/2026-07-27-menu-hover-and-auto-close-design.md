# 菜单面板悬停与自动收回设计

## 目标

- 活动热力图在鼠标悬停时保持格子、行标签和右侧指标位置不变。
- 菜单栏下拉面板在鼠标离开后自动收回。
- GitHub 最近仓库前显示可识别的 GitHub 标志。

## 交互设计

### 活动格悬停

- 删除每个活动格的 macOS 系统 `.help` 浮窗，避免灰色提示遮挡右侧指标。
- 热力图下方始终保留相同尺寸的信息区域。
- 未悬停时显示“少—多”图例；悬停时在同一区域显示日期、Token 和会话数。
- 信息切换不得改变网格、卡片或右侧指标的尺寸。

### 面板自动收回

- 鼠标首次进入面板后启用自动收回。
- 鼠标离开整个面板时等待 300 毫秒再关闭。
- 等待期间重新进入面板会取消关闭，避免操作边缘按钮时误收回。
- 手动收回按钮、点击外部自动关闭和退出功能保持不变。

### GitHub 仓库图标

- 参考密度的仓库项使用白色圆形底和深色 Octocat 标志。
- 标准与紧凑密度继续使用现有仓库图标，避免修改原刘海 GitHub 页面。
- 仓库名称、更新时间、外链和安全链接规则保持不变。

## 验证

- 固定悬停信息区在有、无悬停数据时尺寸一致。
- 自动关闭策略覆盖离开、重新进入取消和未进入面板三个状态。
- 参考仓库密度选择 GitHub 标志。
- 运行完整 macOS 测试并重新生成签名应用包。
