# macOS 参考图等比缩放菜单面板设计

## 目标

以用户在 2026 年 7 月 27 日提供的菜单栏下拉面板参考图作为唯一视觉和排版基准。

本次不重新设计、不重新组合模块、不移动内容，也不删减参考图中的界面元素。菜单栏下拉窗口只对参考图中的整套 UI 做统一等比例缩小，并使用应用中的真实数据替换示例数据。

## 已确认的产品决策

- 点击菜单栏 Codex Monitor 状态区域后打开自定义下拉面板。
- 下拉面板严格采用参考图的单列纵向结构。
- 所有 UI 使用同一个缩放比例。
- 不单独改变某个模块的字体、间距、圆角或卡片比例。
- 面板打开后一次展示完整内容，不使用滚轮查看下方内容。
- 原刘海五页内容、左右滑动、悬停打开和关闭行为保持不变。
- 菜单栏面板与刘海面板共享同一个 `MonitorStore`。

## 面板尺寸

- 目标逻辑尺寸约为 `420 × 720 pt`。
- 宽高比保持参考图面板比例。
- 屏幕可用高度不足时，整套内容继续使用同一个缩放系数缩小，不改变模块布局。
- 禁止只压缩高度或只压缩宽度。
- 禁止在小屏幕上切换为双列、四行网格或其他响应式重排。
- 面板内容不使用横向或纵向 `ScrollView`。

## 模块顺序

从上到下严格保持：

1. 顶部应用状态栏。
2. 本周额度。
3. 每日活动。
4. 项目分析。
5. 统计总览。
6. GitHub 活跃。
7. 底部操作栏。

## 顶部应用状态栏

- 左侧显示紫色 Codex Monitor 标志。
- 显示应用名称 `Codex Monitor`。
- 名称下方显示更新状态和绿色状态点。
- 右侧显示圆形刷新按钮。
- 最右侧显示圆形收起按钮。
- 不增加额外导航、标签、分页或刘海切换按钮。

## 本周额度

- 保持参考图的单张全宽卡片。
- 左侧显示大号剩余额度百分比和 `剩余额度`。
- 右侧显示本周已用百分比、进度条和距离重置时间。
- 标题行显示 `本周额度`、状态点和同步状态。

### 额度数据修复

现有代码会在周额度事件超过 5 分钟后直接隐藏数值。手动刷新只重新扫描本地 JSONL，不会主动让 Codex 生成新额度事件，因此即使磁盘中存在最近有效记录，刘海页面也会持续显示 `—`。

修复后的状态规则：

- 从未读取到周额度事件：数值显示 `—`，状态显示 `等待 Codex 更新`。
- 存在周额度记录且事件不超过 5 分钟：显示额度，状态显示 `已同步`。
- 存在周额度记录但事件超过 5 分钟：继续显示最后一次记录的额度，状态显示 `等待 Codex 更新`。
- 手动刷新立即重新扫描本地会话日志。
- 刷新发现新额度事件时更新数值和状态。
- 刷新未发现新事件时保留最后一次额度，不再清空为 `—`。
- 过期记录不能显示为 `已同步`。

这些状态变化复用参考图标题行中的状态区域，不增加新的卡片、说明行或弹窗。

## 每日活动

- 保持参考图的一张全宽卡片。
- 左侧显示最近 8 周活动热力图。
- 热力格、行标签和颜色图例严格按参考图比例。
- 右侧按四行显示今天 Token、会话、平均每天和连续使用。
- 中间保留竖向分隔线。
- 鼠标悬停格子时显示对应日期、Token 和会话信息。

## 项目分析

- 保持参考图的一张全宽卡片。
- 左上显示标题与当前时间范围。
- 右上显示 `7 天 / 30 天 / 全部` 分段按钮。
- 整个分段按钮区域可点击。
- 左侧显示 Token 柱状图。
- 右侧显示项目、Token 总数和占比排名。
- 中间保留竖向分隔线。
- 鼠标进入排名行时，该行显示紫色低透明度背景和细边框。
- 鼠标离开后恢复参考图默认外观。
- 柱状图与排名行共享现有悬停详情。

## 统计总览

- 保持参考图的一张全宽卡片。
- 五个指标卡横向等宽排列。
- 指标顺序保持为累计 Token、峰值 Token、最长任务时长、当前连续天数、最长连续天数。
- 图标、数值、标签、圆角和间距统一等比例缩小。

## GitHub 活跃

- 保持参考图的一张全宽卡片。
- 左侧显示贡献总数。
- 右侧显示最近 12 个月贡献热力图、月份和星期标签。
- 热力图下方保留颜色图例。
- 最近六个仓库使用两列三行。
- 仓库行显示 GitHub 图标、名称、更新时间和外链图标。
- 点击仓库行或外链图标打开对应 GitHub 地址。
- 鼠标悬停贡献格子时显示日期和贡献次数。
- 未授权状态仍在同一张 GitHub 卡片内显示授权内容，不改变其他模块位置。

## 底部操作栏

- 左侧显示自动刷新说明。
- 右侧显示刷新数据、`⌘R`、退出和 `⌘Q`。
- 结构、分隔线和对齐方式保持参考图。
- 手动刷新与顶部圆形刷新按钮执行相同操作。

## 视觉规范

- 深色半透明背景、灰色细边框和柔和阴影保持参考图风格。
- 主色为紫色，正常状态为绿色。
- 所有文字、图标、卡片、边框、圆角、间距和图表使用统一缩放比例。
- 不把参考图中的全宽模块改为左右并排模块。
- 不改变参考图中的信息层级。
- 遵循 macOS“减少动态效果”设置。

## 性能

- 打开面板时立即显示当前本地快照。
- GitHub 使用缓存先显示，网络刷新在面板出现后进行。
- 活动热力图和 GitHub 热力图继续使用现有高效绘制策略。
- 自动刷新不改变面板尺寸、缩放比例或模块位置。
- 项目排名悬停只修改对应行的视觉状态。

## 验收标准

- 菜单栏下拉面板与参考图的结构、顺序和比例一致。
- 面板只做整体等比例缩小，没有局部重新设计。
- 目标尺寸约为 `420 × 720 pt`。
- 所有模块一页显示，不需要滚轮。
- 刘海五页保持原样。
- 周额度存在旧记录时不再显示空白。
- 旧额度不会错误标记为 `已同步`。
- 手动刷新后不会因为没有新额度事件而清空最后一次记录。
- 项目排名行具有鼠标悬停选中效果。
- 每日活动格和 GitHub 热力格保持参考图中的相对尺寸。
- GitHub 独占全宽卡片并显示两列三行仓库。
- 完整测试通过，最终应用重新签名打包。

## 不在本次范围

- 不修改 Windows 版本。
- 不修改原刘海五页布局。
- 不改变统计口径。
- 不改变 GitHub 授权方式和钥匙串条目。
- 不新增参考图以外的导航或操作入口。
