# 菜单额度进度条动画设计

## 目标

为菜单栏下拉面板“本周额度”中的已用额度进度条增加平滑变化动画，并与现有实时数字动画保持一致。

## 已确认交互

- 每次下拉面板完成显示后，进度条先保持在 0，随后用 1.2 秒平滑增长到实时已用比例。
- 面板显示期间额度刷新时，进度条从当前显示长度平滑过渡到新的实时比例。
- 面板关闭或应用停止时，进度条立即取消未完成动画并无动画归零。
- 面板隐藏期间即使后台数据刷新，进度条仍保持为 0，避免下次打开时短暂显示旧值或最终值。
- 系统启用“减少动态效果”时不播放增长动画，直接显示实时比例。
- 缺少有效额度数据时不显示紫色进度，轨道仍保留。

## 技术设计

新增独立的 `MenuAnimatedQuotaProgress` SwiftUI 视图，输入为可选的 `Double` 目标比例。

视图复用 `MenuNumberAnimationContext`：

- 监听 `cycle`，每次面板展示时从 0 重播。
- 监听 `isPresented`，面板关闭时取消任务并归零。
- 监听目标比例，面板展示期间从当前值动画到新值；隐藏时保持 0。
- 监听系统“减少动态效果”设置，并遵循与数字动画相同的展示规则。

比例在进入视图前统一限制为 `0...1`。紫色胶囊宽度由动画中的实时比例乘以轨道宽度计算，轨道结构、颜色、高度和页面排版不改变。

## 动画节奏

- 起始零值停留：60 毫秒。
- 增长动画：`easeOut`，持续 1.2 秒。
- 刷新动画：`easeOut`，持续 1.2 秒。

进度条与相邻数字同时启动，使百分比与滑动条变化保持同步。

## 测试范围

- 普通动画模式的初始比例为 0。
- 减少动态效果模式的初始比例为实时目标值。
- 输入比例会限制在 `0...1`。
- 面板隐藏时的数据更新保持 0。
- 面板显示时选择平滑更新，减少动态效果时选择立即更新。
- 现有菜单、额度展示和完整应用测试不得回归。
