# 菜单数字动画节奏优化设计

## 目标

解决菜单栏下拉面板数字滚动过快、用户无法看清变化过程的问题，同时保持现有布局、数据范围和悬停交互不变。

## 动画节奏

- 动态数字滚动时长由 0.45 秒调整为 1.2 秒。
- 项目 Token 柱状图增长时长由 0.45 秒调整为 1.0 秒。
- 两类动画都使用先快后慢的缓出曲线，让最终数值更容易辨认。
- 每次打开面板时从零值播放到当前值。
- 刷新导致数据变化时，从旧值播放到新值。
- macOS 开启“减少动态效果”时继续直接显示最终状态，不播放动画。

## 包含范围

- 本周剩余额度、已用比例、距离重置时间。
- 今日 Token、会话数、平均值、连续使用天数。
- 项目分析 Token 总量、项目排名数值和 Token 柱状图。
- 统计总览的全部动态指标。
- GitHub 总贡献数。

## 排除范围

以下文字中的数字保持静态，不播放滚动动画：

- `最近 8 周`等区块说明。
- `7 天`、`30 天`等筛选按钮。
- 月份、日期和星期。
- 仓库的相对更新时间。
- 底部自动刷新时间说明。
- 鼠标悬停提示中的日期、Token 和会话文字。

## 实现方式

统一数字组件和柱状图组件分别读取集中定义的动画时长，避免各页面出现不同速度。只修改动画参数，不调整数值格式、字号、间距、颜色和面板尺寸。

## 完成标准

- 打开面板后，动态数字的滚动过程清晰可见。
- 数字动画约 1.2 秒完成，柱状图约 1.0 秒完成。
- 刷新后的数值变化使用相同节奏。
- 静态说明文字中的数字不播放动画。
- 动画期间布局不跳动，悬停打开与自动收回行为不受影响。
